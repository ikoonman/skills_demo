## About this project

This is a **dummy test project**. It has no real users, customers or data, and nothing in it is maintained as a product.

It exists so that a Git integration can be tested against a real repository with real commits, pull requests, reviews and comments. The app is a single page called "Customer Portal" with a few controls (search, filters and a notes form) over made-up sample data.

For more about the product this project helps test, see [Teamcentric.io](https://teamcentric.io).

## Getting started

You need [Node.js](https://nodejs.org) 20 or later.

```bash
npm install
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5173).

Other commands:

- `npm run build`: type-checks and builds the app into `dist/`.
- `npm run preview`: serves the built app locally.
